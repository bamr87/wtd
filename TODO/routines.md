# Routine TODOs

Recurring tasks that need regular attention. WTD automatically tracks when these are due.

## Daily Routines

- [routine:daily] Review and triage new issues
- [routine:daily] Run test suite and check CI status
- [routine:daily:workday] Check Slack/email for blockers

## Weekly Routines

- [routine:weekly:monday] Sprint planning and backlog grooming
- [routine:weekly:friday] Code review catchup and PR merges
- [routine:weekly] Update project documentation
- [routine:weekly] Security dependency audit

## Biweekly Routines

- [routine:biweekly] Performance profiling and optimization review
- [routine:biweekly] Refactoring debt assessment

## Monthly Routines

- [routine:monthly:1] Generate monthly progress report
- [routine:monthly] Review and update roadmap
- [routine:monthly] Backup and archive old branches
- [routine:monthly] Review and rotate API keys/secrets

## Quarterly Routines

- [routine:quarterly] Major dependency upgrades
- [routine:quarterly] Architecture review and tech debt prioritization
- [routine:quarterly] Team retrospective and process improvements

## Conditional Routines

- [routine:on-release] Update changelog and version numbers
- [routine:on-pr] Run full integration test suite
- [routine:on-deploy] Verify production health metrics
- [routine:on-error-spike] Review error logs and create tickets

## Custom Interval Routines

- [routine:every-3-days] Check external API health
- [routine:every-2-weeks] Review analytics and usage patterns
